# woahscope

Inspired by the fantastic work of the original [woscope](https://github.com/m1el/woscope) project by m1el, and Neil Thapen's [XXY OSCILLOSCOPE](https://dood.al/oscilloscope/), I made a version with the same spectacular shaders, updated to use React Three Fiber. Made it responsive too, so you can enjoy an oscilloscope emulator in your pocket computer. 

Here's a [live demo](https://woahscope.vercel.app), have fun with it. 

### Set up locally

```
npm install
```

```
npm run dev
```

Go to the local URL shown (probably http://localhost:5173). Make some fun edits.
